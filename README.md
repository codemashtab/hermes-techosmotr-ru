# 🩺 Техосмотр Hermes Agent — на русском

Проверяет здоровье вашего [Hermes Agent](https://hermes-agent.nousresearch.com/) и объясняет результат **простым языком**: всё в порядке или что не так и что делать.

```
⚠️ Техосмотр агента: есть замечания.
Проверено разделов: 12, замечаний: 1.

⚠️ Настройки (config.yaml) (профиль «sales»): Нет файла настроек config.yaml
   → что сделать: Run hermes --profile sales config path to verify the profile.

Диагностика только читает: ничего не изменено и не перезапущено.
```

## Что проверяется
Профили, настройки, шлюз сообщений (Telegram и др.), расписания, журналы ошибок, память, навыки, плагины, MCP-серверы, изменения после обновления.

Под капотом — [hermes-system-doctor](https://github.com/AlekseiUL/hermes-system-doctor) (MIT, автор — [@Sprut_AI](https://t.me/Sprut_AI)): **только чтение**, без сети, без перезапусков, секреты в отчёт не попадают. Мы добавили русскую сводку, навык для агента и отправку в Telegram.

## Установка (Linux / WSL, 1 минута)
```bash
git clone https://github.com/codemashtab/hermes-techosmotr-ru
cd hermes-techosmotr-ru
./install.sh
```

## Как пользоваться
- **Сам:** `python3 ~/techosmotr/techosmotr.py` (подробно — `--full`).
- **Через агента:** напишите ему «проведи техосмотр» — навык `techosmotr` уже установлен.
- **Раз в неделю в Telegram:** см. строку для `crontab`, которую выводит `install.sh`. Токен бота и chat id — только в переменных окружения, не в файлах.

Код выхода: `0` — всё хорошо, `1` — замечания, `2` — проблемы (удобно для мониторинга).

## Безопасность
- Скрипт ничего не исправляет. Команду исправления (`fix --execute`) навык запрещает запускать без явного «да» владельца.
- Ключи, токены и пароли не читаются и не выводятся.
